# 📊 SPX & NASDAQ 场内 ETF 实时溢价监控与大盘水位雷达

> 本项目专注于 **美股纳斯达克 100 与标普 500 跨境场内 ETF** 的实时折溢价监控、大盘水位回撤雷达与渠道套利决策。

---

## 🚀 核心架构与功能

1. **场内 ETF 实时折溢价监控**：
   - 覆盖主流场内纳指（513100、159941、513300、159659等）与标普（513500、159612等）标的。
   - 双轨制估值引擎：腾讯财经高频接口实时行情 + 新浪美股实时期货（NQ/ES）与 USD/CNH 汇率联动。
2. **大盘水位雷达 (Drawdown Signal)**：
   - 现货正股锚定历史最高点（ATH），计算回撤深度。
   - 智能四级状态感知：安全（绿）、回调（黄）、修正大跌（橙）、熊市大底（红）。
   - ⚡ 闪电暴跌日内突发预警（实时期货跌幅 >= -1.5% 时自动弹出高亮套利警报）。
3. **跨境南向通比价与临界溢价计算器**：
   - 结合持有期限、预期涨幅、税费差异，动态计算“南向通等效溢价”。
   - 智能推荐“💎买场内”或“✈️转战南向通”。
4. **内置科学兵法指南**：
   - 侧边栏集成完整的 4 种极端市场场景应对策略与参数指导。

## ⏱️ 定时调度与秒级唤醒体系

本项目已无缝接入 **Cloudflare Workers 全局中央调度中枢 (`github-action-cron-dispatcher`)**：

- **自动化触发机制**：
  - 复用 Cloudflare Workers 准时边缘定时器（交易日 08:45、10:30、14:00、16:30、20:30），**0 额外占用 Cron 触发器额度**。
  - 通过 GitHub API 毫秒级触发本仓库的 [`.github/workflows/wake_up.yml`](.github/workflows/wake_up.yml)。
- **唤醒与巡检内容**：
  - 自动巡检腾讯 ETF 行情、新浪期货与大盘水位接口状态。
  - 静默向 Streamlit 网页发送活跃心跳，彻底防止 7 天无访问休眠。
- **专属外部 Webhook 接口**：
  - 触发本监控：`GET https://github-action-cron-dispatcher.ozr2117.workers.dev/trigger-np`
  - 全局联动触发：`GET https://github-action-cron-dispatcher.ozr2117.workers.dev/trigger`
